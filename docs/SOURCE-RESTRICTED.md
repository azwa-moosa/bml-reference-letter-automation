# `docs/source/` is RESTRICTED

`docs/source/er-automation-prototype.html` and `docs/source/er-automation-spec.md` are the **SHA-pinned baseline** (see `docs/BASELINE.md`). They are kept byte-for-byte unchanged, so they still contain the names used in the original prototype, including real staff names.

Rules:
- **Do not edit** these files (the recorded SHA-256 would no longer match).
- **Do not copy them into demos, screenshots, handovers to other teams or deployments.** The app does not read them; it uses `src/`, `prisma/` and `config/`, which contain placeholders only (hardening RL-G06).
- Share them only with the module owner and the people who maintain this baseline.
- When the baseline is retired, move the folder out of the repository rather than editing it.
